# Port Scanner

Scanner de portas TCP feito em Python. Meu primeiro projeto de segurança.
Ele descobre quais portas estão abertas em um computador.

## O que faz
- Pergunta o IP do alvo
- Testa as portas de 1 a 1024
- Mostra as portas abertas e quantas foram encontradas

## Como usar
python scanner.py

## O que eu aprendi
- Como funciona uma conexão TCP e o que são portas
- A diferença entre uma porta estar aberta só no 127.0.0.1 (local) e no 0.0.0.0 (exposta para a rede)
- Escaneando meu próprio PC, encontrei um servidor que eu tinha deixado exposto na rede sem querer
